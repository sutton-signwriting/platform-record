*Top-level archival record for the Sutton SignWriting complete eight-series release*

This repository contains the public platform record for the Sutton SignWriting Platform: Complete Eight-Series Release. It is the umbrella publication record that links eight coordinated series on signed-language writing, evidence, writing-system theory, Formal SignWriting, literacy research, critical review, infrastructure, and Unicode-facing work.

The platform record is the release-level entry point. It explains how the eight series fit together, how the platform DOI should be used, and where readers should go for series-level and artifact-level claims.

## Scope

This repository contains the platform-level record and supplemental navigation/context files. It does not duplicate the full contents of the eight series repositories. Each series remains citable through its own Zenodo DOI and source repository.

The platform record is not a software application or a claim of community authority. It is a coordinated archival publication and infrastructure record for the complete release.
